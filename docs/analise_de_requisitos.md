# Análise de Requisitos - Projeto Sauce Demo

## Aplicação a ser testada
- URL: [Sauce Demo](https://www.saucedemo.com/)
- Funcionalidade principal: Login e Logout de usuário

## Objetivo
O objetivo desta análise é identificar os requisitos e critérios de aceite para o teste da funcionalidade de login, garantindo que o processo de autenticação funcione corretamente em diferentes cenários.

## Requisitos Funcionais
- RF01: O usuário deve conseguir fazer login com usuário e senha válidos.
- RF02: O sistema deve exibir mensagem de erro ao inserir usuário ou senha inválidos.
- RF03: Usuário autenticado deve ser redirecionado para a página principal de produtos.
- RF04: O sistema deve exibir mensagem de erro ao tentar logar com campos vazios.
- RF05: O sistema deve permitir que o usuário saia do sistema (logout).

## Requisitos Não Funcionais
- RNF01: O layout deve ser compatível com o navegador Edge.

## Critérios de Aceite
- Login com usuário/senha válidos funciona corretamente.
- Mensagem de erro é exibida ao inserir dados incorretos.
- Mensagem de erro é exibida ao tentar logar com campos vazios.
- Redirecionamento para a página de produtos ocorre corretamente.
- Logout é funcional.
